# LLC Converter Simulation Dataset

Simulated waveforms of a full-bridge LLC resonant converter, generated with MATLAB/Simulink.
They are used to train and evaluate the physics-informed forward surrogate (circuit parameters → waveforms)
and the inverse surrogate (waveforms → circuit parameters), and to run the capacitor-aging and agent case studies.

## Files

| File | Samples | Purpose | Generated by |
|---|---|---|---|
| `llc_dataset_simulink_2.mat` | 300 | **Main dataset**: training / validation / test of the forward and inverse models | `generate_dataset_2.m` |
| `llc_aging_trajectory.mat` | 39 | Controlled output-capacitor aging: $C_o$ from 100 % to 70 % of nameplate (13 levels) × 3 loads | `generate_aging_trajectory.m` |
| `llc_agent_v2_cases.mat` | 7 | Special operating cases for the agent evaluation (out-of-range parameters, mismatched $V_{in}$ / $f_s$) | `generate_agent_v2_cases.m` |
| `LLC_simu.slx` | – | Simulink model used by all generation scripts | – |
| `setparams.m` | 1 | Sets the nameplate parameters and runs one nominal simulation (reference waveform) | – |

All `.mat` files share the same field layout (see [Fields](#fields)).

## Circuit and sampling settings

**Nameplate parameters**

| Parameter | Value |
|---|---|
| Input voltage $V_{in}$ | 311 V |
| Switching frequency $f_s$ | 90 kHz |
| Duty cycle $D$ | 45 % |
| Transformer turns ratio $n$ | 6.5 |
| Resonant inductance $L_r$ | 73 µH |
| Resonant capacitance $C_r$ | 35 nF |
| Magnetizing inductance $L_m$ | 146 µH |
| Output capacitance $C_o$ | 2200 µF |
| Rated load $R_o$ | 2 Ω |

**Sampled ranges (main dataset)** — Latin hypercube sampling over five parameters, random seed 42:

| Parameter | Range |
|---|---|
| $L_r$, $C_r$, $L_m$, $C_o$ | ±20 % of nameplate |
| $R_o$ | 1–4 Ω (0.5–2 × rated) |
| $V_{in}$, $f_s$, $D$, $n$ | fixed at nameplate |

**Waveform recording**

- Simulation time 0.02 s from cold start; the steady-state window is the **last 10 switching periods**, sampled at 200 points per period → 2001 points per channel (sampling interval 55.6 ns).
- Channels: $i_{Lr}$, $i_{Lm}$, $v_{Cr}$, $v_o$.
- The cold-start output voltage $v_o(t)$ is also recorded at one point per half switching period (3001 points). Its first few points carry most of the information about $C_o$, which steady-state waveforms alone cannot identify.

## Fields

`N` is the number of samples in the file.

| Field | Shape | Unit | Description |
|---|---|---|---|
| `states` | N × 2001 × 4 | A, A, V, V | Steady-state waveforms $[i_{Lr}, i_{Lm}, v_{Cr}, v_o]$ |
| `vab_real` | N × 2000 | V | Measured primary-side bridge voltage $v_{ab}$ (includes dead time); drives the physics residual |
| `v_sq_ideal` | N × 2000 | V | Ideal ±$V_{in}$ square wave (kept for reference only) |
| `vo_transient` | N × 3001 | V | Cold-start $v_o$, one point per half switching period |
| `settling_time` | N × 1 | s | Time at which cold-start $v_o$ enters and stays within ±2 % |
| `Lr`, `Cr`, `Lm`, `Co` | N × 1 | H, F, H, F | Circuit parameters (ground truth) |
| `rload` | N × 1 | Ω | Load resistance (ground truth) |
| `vin`, `fs`, `duty`, `n` | N × 1 | V, Hz, %, – | Operating point and turns ratio |
| `dt_half` | N × 1 | s | Sampling interval of `states` |
| `co_ratio` | N × 1 | – | *Aging file only*: true $C_o$ / nameplate |
| `case_name` | N × 1 | – | *Agent-case file only*: case label (`lr130`, `lm070`, `ro5`, `cr130`, `vin280`, `vin340`, `fs85k`) |

## Train / validation / test split

The main dataset is converted to NumPy and split 150 / 30 / 120 (50 % / 10 % / 40 %, seed 42) by

```bash
python mat_to_npz.py dataset/llc_dataset_simulink_2.mat data/llc_dataset_simulink_2
```

which writes `data/llc_dataset_simulink_2_{train,val,test}.npz`. Outlier filtering is applied before splitting; with the provided file no samples are removed.

## Regenerating the data

Requirements: MATLAB with Simulink and Simscape Electrical (the model `LLC_simu.slx` must be saved in this folder), plus the Statistics and Machine Learning Toolbox for `lhsdesign`.

```matlab
run('dataset/generate_dataset_2.m')          % main dataset, ~300 simulations
run('dataset/generate_aging_trajectory.m')   % aging trajectory
run('dataset/generate_agent_v2_cases.m')     % agent special cases
```

Each script saves its `.mat` file next to itself. Results can differ slightly across MATLAB/Simulink versions because of solver changes.

## Description of the auxiliary sets

**Aging trajectory.** $L_r$, $C_r$, $L_m$ are fixed at nameplate; $C_o$ decreases from 100 % to 70 % in 2.5 % steps at $R_o$ = 1.5, 2 and 3 Ω. Points below 80 % lie outside the training range and test extrapolation. Health bands used in the paper: healthy (≥ 90 %), attention (80–90 %), end of life (< 80 %).

**Agent special cases.**

| Case | Deviation |
|---|---|
| `lr130` | $L_r$ = 130 % of nameplate (outside training range) |
| `cr130` | $C_r$ = 130 % |
| `lm070` | $L_m$ = 70 % |
| `ro5` | $R_o$ = 5 Ω |
| `vin280`, `vin340` | $V_{in}$ = 280 V / 340 V (training data uses 311 V only) |
| `fs85k` | $f_s$ = 85 kHz (training data uses 90 kHz only) |
